# 🐍 Camorro — مساعد اختبار الاختراق بالذكاء الاصطناعي

كامورو: مساعد هكر ذكي يعمل **محليًا 100%** على جهازك، يتكلم الدارجة المغربية وجميع اللغات، يحلل كل شيء، وينفذ أدوات الاختراق بنفسه.

## ✨ المميزات
- 🤖 يعتمد على نموذج LLM محلي (Ollama) — لا يحتاج إنترنت
- 🗣️ يرد بالدارجة المغربية / العربية / الإنجليزية / الفرنسية حسب لغة المستخدم
- 🛠️ ينفذ أدوات الاختراق: nmap, sqlmap, subfinder, nuclei, curl, whois...
- 📁 يقرأ ويكتب الملفات في مساحة عمل آمنة (workspace)
- 🌐 واجهة ويب عربية RTL + واجهة طرفية
- 🛡️ حماية من الأوامر الخطيرة على النظام

## ⚙️ التثبيت

### 1. ثبّت Python و Ollama

# Ollama (Linux / macOS / Windows)
curl -fsSL https://ollama.com/install.sh | sh

# حمّل نموذج يدعم العربية (أفضل لجهاز 8GB+ رام)

# بديل متعدد اللغات ممتاز:
